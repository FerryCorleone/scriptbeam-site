Support

How can we help?

ScriptBeam supports iPhone and iPad on iOS/iPadOS 17 or later, plus supported Macs through Mac Catalyst.

Common checks

  • Voice Follow: allow Microphone and Speech Recognition access, select the script language, and reduce background noise.
  • Offline recognition: availability depends on Apple system models. Turn off Prefer On-Device Recognition if the selected language is unavailable offline.
  • iCloud import: wait for a cloud file to finish downloading in Files before importing it.
  • Nearby Remote: allow Local Network access on both devices and keep them on the same Wi-Fi network or physically nearby.
  • Physical teleprompter: start with horizontal mirroring. Add vertical mirroring only when the optical path requires it.

Recording with Prompt

Fixed-speed, timed, WPM, and Voice Follow modes work over the live camera preview. Recordings remain temporary until you save them to Photos or share them.

Contact support

Email qiezi.products@gmail.com. Include the app version and build, device model, OS version, recognition language, document format, and steps to reproduce. Remove sensitive script content before attaching a file.

For privacy or data requests, include Privacy Request in the subject.
